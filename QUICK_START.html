ExecutionLab

One project for stock monitoring, crypto monitoring, and execution research.

Start in three steps

  1. Extract the entire ZIP into a writable folder.
  2. Install Python 3.10 or newer, including its launcher or PATH option.
  3. Double-click START_HERE.cmd and choose a mode.

Try the stock demo first. It uses clearly labeled synthetic data and requires no keys. Keep the monitor terminal open; Ctrl+C stops it.

Choose a mode

ModeWhat you need
Stock demoPython only
Stocks liveAlpaca API key and secret; default IEX coverage only
Crypto liveInternet connection; no API key
Backtest reportBrowser only

The stock monitor opens at http://127.0.0.1:8766; crypto uses port 8765. You can run them side by side from separate launcher windows.

Set up stocks

Obtain your paper-account API keys from the Alpaca dashboard. The stock launcher asks for them locally using hidden input. Keys are held in memory, not saved in preferences. Choose the matching account type in the start menu settings. See STOCKS.md for details.

IEX is one exchange, not whole-market coverage. SIP requires the corresponding account entitlement. Stock detection pauses outside the regular session; leave it running to resume at the next open. API access has not been verified in this build environment.

Make it yours

Choose “Change watchlists/settings” in the start menu to save stock and crypto watchlists, interval, stock feed, and account type. Preferences contain no credentials. Existing single-purpose launchers retain their own defaults; saved preferences apply through START_HERE.

Use the dashboard

  • Search by ticker or sort confirmed conditions first.
  • Watch baseline progress and data-quality/retry diagnostics.
  • Select a chart and download observations or alert history.
  • Use the hypothetical execution-cost calculator to estimate covered quantity, spread cost, and your assumed fee.

For stocks, the calculator requires a verified shares-per-reported-lot conversion. It does not assume all lots equal 100 shares. It accounts only for displayed coverage and disables itself on stale or disconnected data. It sends no orders and does not model market impact.

Troubleshooting

  • Python missing: install Python 3.10+ with launcher/PATH support.
  • Port already in use: close the earlier monitor or use its existing browser tab.
  • Market closed: stock detection resumes after the provider reports the next regular open.
  • 401/403: verify keys, paper/live account choice, and feed entitlement.
  • Stale/disconnected: check your network and computer clock. Historical observations are not shown as current signals.

Recordings are saved in output/monitor/. Logs split into new files at approximately 5 MB each; previous files are retained. Stop the app when you no longer need collection. Statistical deviations do not establish fair value or profitable trades.
